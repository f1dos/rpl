Подключение к Flashscore

Приложение берёт свежие результаты, составы, статистику матчей и рейтинги игроков у Flashscore через небольшой локальный прокси. Запусти его на своём компьютере:

python rpl_flashscore_proxy.py

Нужен только Python 3.9+, никаких библиотек ставить не надо. Сервер слушает адрес ниже. Если Flashscore у тебя открывается только через VPN — включи его.
