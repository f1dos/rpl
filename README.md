Как подключить Flashscore

Положи прокси в одну папку с HTML-файлом (сейчас оба уже в «Загрузках»).
Запусти его командой python rpl_flashscore_proxy.py. Нужен только Python, ставить ничего не надо.
Открой в браузере http://localhost:8765/ — приложение подключится само.
Кнопка ↻ обновляет результаты и составы и подгружает протоколы новых матчей. Во время матчей счёт обновляется раз в минуту.

Что не удалось проверить: запустить прокси на твоём компьютере у меня не было возможности. Разбор данных я сверил на настоящих ответах Flashscore, а запросы — на этих же адресах в браузере. Но сами запросы из Python никто ещё не делал. Если Flashscore у тебя открывается только через VPN, включи его перед запуском.

Данные в файле актуальны на 28 октября, после 12-го тура.
