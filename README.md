Как запустить (локально)

Положи rpl_flashscore_proxy.py в одну папку с rpl_arena_v6.html и запусти: python rpl_flashscore_proxy.py
Нужен только Python 3.9+, ставить ничего не надо. Открой http://localhost:8765/ — приложение подключится само.
Кнопка ↻ обновляет результаты и составы и подгружает протоколы новых матчей.
Если Flashscore у тебя открывается только через VPN, включи его перед запуском.

Как выложить для пользователей

Сервер отдаёт и сам сайт, и API с одного адреса, поэтому пользователям ничего запускать не нужно:
  PORT=8080 python rpl_flashscore_proxy.py            (слушает 0.0.0.0)
  или Docker:  docker build -t rpl . && docker run -p 8080:8080 -v rpl-cache:/app/.cache rpl
Открытый на размещённом домене сайт сам ходит за данными на тот же адрес. Запускать нужно ОДИН экземпляр
(кэш и фоновое обновление живут в памяти процесса). Папку CACHE_DIR (по умолчанию ./.cache) лучше
примонтировать как постоянный том — тогда после перезапуска данные есть сразу.
Проверка: GET /health показывает возраст данных, признак устаревания и последнюю ошибку источника.

Почему это не «работает через раз»

Раньше каждый клик пользователя превращался в запросы к Flashscore, и любой сбой был виден сразу.
Теперь:
  • сезон и составы обновляются в фоне (раз в минуту, пока идёт матч или он скоро; иначе раз в 10 минут;
    составы — раз в 6 часов), пользователь получает готовый снимок из памяти;
  • каждый запрос к Flashscore идёт с повторами и паузами, общим лимитом параллельности и проверкой,
    что пришла настоящая страница, а не заглушка;
  • если Flashscore недоступен, отдаётся последний удачный снимок с пометкой meta.stale (в приложении
    это видно в тосте и в статусе API); если не ответили лишь несколько клубов — остальные данные целы;
  • снимки пишутся на диск и переживают перезапуск; протоколы сыгранных матчей кэшируются навсегда;
  • неизвестные id матчей и игроков во Flashscore не пробрасываются.
Настройки окружения: PORT, HOST, CACHE_DIR, FLASHSCORE_SITE, FLASHSCORE_FEED, FLASHSCORE_FSIGN
(три последние — на случай, если Flashscore поменяет адреса или подпись, не правя код).

Что проверено, а что нет

Проверено автотестами на локальной имитации Flashscore, собранной из реальных образцов лент
(python -m unittest discover -s tests -p "test_proxy.py"): повторы при 503, заглушка вместо страницы,
полный блэкаут, падение страницы одного клуба, перезапуск с диска, сквозная работа HTTP-сервера;
плюс прогон приложения в браузере через живой процесс сервера, включая «падение» Flashscore посреди сессии.
Не проверено: реальные запросы к самому Flashscore из этого окружения (доступ закрыт). Если у них поменялась
вёрстка или подпись, разбор сломается — тогда /health покажет failStreak и lastError, а пользователи
продолжат видеть последний снимок. Это неофициальный доступ к публичным страницам: условия использования
данных Flashscore нужно проверить до публичного запуска.

Данные в файле актуальны на 28 октября, после 12-го тура.


Интерфейс Arena
---------------
Сохранена тёмно-синяя палитра с лаймовым акцентом; обновлены типографика,
сетка, карточки, таблицы и мобильные экраны. HTML остаётся самостоятельным:
можно открыть rpl_arena_v6.html без сборки или запустить прокси, как описано выше.

• «Мои клубы»: выбор нескольких команд, ближайшие матчи и результаты.
  Избранное хранится только в localStorage текущего браузера.
• «Сравнить команды»: показатели двух клубов и очные встречи по завершённым
  матчам из текущей базы. При выборе одинаковой команды стороны меняются местами.
• Эмблемы размещаются в ограниченных контейнерах с object-fit: contain;
  исходные пропорции сохраняются, изображения не расширяют сетку.

Проверка интерфейса
------------------
Для разработки: npm install --no-save playwright, затем npx playwright install chromium.
Запустить python -m http.server 8766 и в другом терминале node tests/interface.cjs.
Можно передать RPL_TEST_URL для другого адреса. Тест подменяет удалённые
изображения крупными SVG, проверяет границы эмблем на пяти ширинах,
избранное, сравнение и существующие страницы. Доступность Flashscore он не проверяет.
