Как подключить Flashscore

Положи прокси в одну папку с HTML-файлом (сейчас оба уже в «Загрузках»).
Запусти его командой python rpl_flashscore_proxy.py. Нужен только Python, ставить ничего не надо.
Открой в браузере http://localhost:8765/ — приложение подключится само.
Кнопка ↻ обновляет результаты и составы и подгружает протоколы новых матчей. Во время матчей счёт обновляется раз в минуту.

Что не удалось проверить: запустить прокси на твоём компьютере у меня не было возможности. Разбор данных я сверил на настоящих ответах Flashscore, а запросы — на этих же адресах в браузере. Но сами запросы из Python никто ещё не делал. Если Flashscore у тебя открывается только через VPN, включи его перед запуском.

Данные в файле актуальны на 28 октября, после 12-го тура.


Интерфейс Arena
---------------
Сохранена тёмно-синяя палитра с лаймовым акцентом; обновлены типографика,
сетка, карточки, таблицы и мобильные экраны. HTML остаётся самостоятельным:
можно открыть rpl_arena_v6.html без сборки или запустить прокси, как описано выше.

• «Мои клубы»: выбор нескольких команд, ближайшие матчи и результаты.
  Избранное хранится только в localStorage текущего браузера.
• «Сравнить команды»: показатели двух клубов и очные встречи по завершённым
  матчам из текущей базы. При выборе одинаковой команды стороны меняются местами.
• Эмблемы размещаются в ограниченных контейнерах с object-fit: contain;
  исходные пропорции сохраняются, изображения не расширяют сетку.

Проверка интерфейса
------------------
Для разработки: npm install --no-save playwright, затем npx playwright install chromium.
Запустить python -m http.server 8766 и в другом терминале node tests/interface.cjs.
Можно передать RPL_TEST_URL для другого адреса. Тест подменяет удалённые
изображения крупными SVG, проверяет границы эмблем на пяти ширинах,
избранное, сравнение и существующие страницы. Доступность Flashscore он не проверяет.
